# Voltura Books 0.1.1

Read while you browse, and get back to your books faster.

## What's new

- Read PDFs, EPUBs, RTF, TXT, DOCX, and HTML/HTM files directly in **Browse books**.
  PDFs continue from the first-page preview; EPUBs retain their chapters,
  styling, and images. RTF preserves supported formatting and embedded pictures, with automatic
  fit-to-page zoom in the preview and fullscreen reader.
  HTML shows inline styles and embedded images without loading companion files.
  DOCX shows supported formatting, tables, embedded images, headers, footers,
  and notes without Word or LibreOffice. Its arrows move by a screenful;
  pagination can differ from Word and Kindle. Word 97–2003 DOC files now convert
  locally when reading starts and use the same formatted reader, preserving
  supported formatting, tables, and embedded pictures. The original file is
  still sent unchanged and used by **Open with default app**.
- Turn pages with the controls at the left and right edges or with the arrow
  keys. Use the new fullscreen reader for a more comfortable view; **F11**
  toggles fullscreen and **Esc** returns to Browse books.
- Keep your place when resizing the window or switching between the normal and
  fullscreen reader.
- View JPEG, PNG, GIF, and BMP images in full screen, with previews rendered for
  the larger view. Use **Read in full screen** for documents or **View in full
  screen** for images; the corner control explains how to enter or exit.
- Read large text files in small chunks, without the previous 8 MB reading
  cutoff. Reading content loads on demand, and formatted readers use a memory
  budget to avoid excessive resource use. If formatting cannot be displayed,
  choose **Read as text** or **Open with default app**.
- See a centered spinner and clear status while a document opens. Slower page
  changes and fullscreen layout show **Loading page…** or **Preparing view…**,
  while closing the reader and exiting fullscreen remain responsive.
- Open browsing directly from the new **Voltura Books - Browse books** Start
  menu shortcut or with `--browse`. Closing Browse books exits browsing without
  opening the sending window, including when opened through **Browse folder**.
- Open **Browse folder** without choosing a folder every time. Voltura Books
  remembers the folder last selected through **Choose folder...**. On first
  use, it opens Downloads, falls back to Documents, and only shows the folder
  picker when neither is available.
- Clear a filename search with the new clear button. The sorting menu offers
  name order and newest/oldest modified date, and the image filter is now
  labelled **Images**.
- See clearer keyboard focus indicators across controls, with support for
  Windows' always-visible focus setting and high contrast. Browse controls and
  details actions have more consistent sizing and alignment. Scrollbars in the
  reader, book list, Tiles view, and Settings follow the app theme.
- Avoid seeing the same EPUB cover twice: an opening that consists only of the
  already-displayed cover image is skipped; distinct opening content is kept.
- Try sending with clearer **Don't send emails** and **Test sending** labels.
  The simulation sends no email and leaves sent-book history unchanged. Use
  `--test-sending` (replacing `--preview`) or `--browse --test-sending` to launch
  it directly. Reading and fullscreen previews never send emails.
- Continue using **Open with default app** whenever the built-in reader is not
  available or a book uses unsupported protection.

Reading stays on the PC. Book scripts, external links, and remote resources are
blocked. DRM-protected or encrypted EPUBs, encrypted DOC/DOCX, damaged or
pre-97 DOC files, and password-protected PDFs are not supported by the built-in
reader. Reader data created by the app is removed when Voltura Books is
uninstalled.

Sending continues to support EPUB, PDF, Word documents, RTF, text, HTML, and
supported image files, up to 50 MB per file. Amazon handles conversion and
delivery; AZW, AZW3, and MOBI are not supported by email.

## Install

Download **VolturaBooks-Setup-0.1.1-win-x64.exe** and run it. Installation is for your Windows account. Enter your Kindle and sender email addresses in Settings, and approve the sender address in your Amazon account.

EPUB, HTML, DOC, and DOCX reading use Microsoft Edge WebView2 Runtime, which is
normally included with Windows 11. DOC conversion uses .NET Framework 4.8,
included with Windows 11, and does not require Word or LibreOffice. The rest of
Voltura Books remains available if WebView2 is missing. EPUBs can still be opened
in their usual app, and HTML and DOCX—including successfully converted DOC—also
offer text-only reading. Sending always attaches the original document unchanged.

Designed and tested for Windows 11 x64. Windows 10 compatibility is not verified. Windows 8 and 8.1 are not supported. This release is unsigned, so Windows may show a publisher warning.

The ZIP contains the unpacked app and installation scripts. SHA256SUMS.txt provides checksums for both downloads.

## Delivery

“Email sent” means the mail server accepted the message; Amazon may take a few minutes to deliver it. Direct sending can be blocked by your network and may be unencrypted. Provider sending requires verified TLS. Browser-based email sign-in is not supported.
