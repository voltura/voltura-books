# Voltura Books 0.1.2

Browse and send from Explorer with clearer Voltura Books commands.

## What's new

- Right-click a supported book, document, or image and choose **Send to Kindle with Voltura Books** from the classic Explorer menu.
- Right-click a folder and choose **Browse with Voltura Books** to open it directly in Browse books.
- On Windows 11, find both commands under **Show more options**.
- Return to the folder later: folders opened from Explorer become the remembered Browse books folder.
- Keep one focused browsing window. If Browse books is already open, the Explorer command switches it to the selected folder.
- View the restored Browse books screenshot and updated Explorer instructions on the Voltura Books website.

Your reading stays on your PC, and browsing, reading, or previewing a book never sends an email.

## Install

Download **VolturaBooks-Setup-0.1.2-win-x64.exe** and run it. Then enter your Kindle and sender email addresses in Settings and approve the sender address in your Amazon account.

Voltura Books is designed and tested for Windows 11 x64. This release is unsigned, so Windows may show a publisher warning.

## Sending books

Voltura Books can send EPUB, PDF, RTF, TXT, HTML/HTM, DOC/DOCX, JPEG/JPG, PNG, GIF, and BMP files up to 50 MB. Amazon handles conversion and delivery, which may take a few minutes after the email has been accepted.
