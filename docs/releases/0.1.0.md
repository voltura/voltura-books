# Voltura Books 0.1.0

Send books and documents to your Kindle from your Windows PC.

- Select one or several files in Explorer and choose **Send to Kindle** from the classic right-click menu.
- Open **Voltura Books - Send a book** from Start to drop files, choose files, or browse a folder.
- Preview covers and book details. Search, filter by file type, sort, and switch between a list and thumbnails.
- Send several books one at a time, with clear progress and reminders for books already sent.
- Use your email provider or direct sending. Passwords stay in Windows Credential Manager.
- Check for updates from About, download a verified update, and choose when to install.
- Try the interface with **Preview only**, which sends no emails.

Supports EPUB, PDF, Word documents, RTF, text, HTML, and supported image files, up to 50 MB per file. Amazon handles conversion and delivery; AZW, AZW3, and MOBI are not supported by email.

## Install

Download **VolturaBooks-Setup-0.1.0-win-x64.exe** and run it. Installation is for your Windows account. Enter your Kindle and sender email addresses in Settings, and approve the sender address in your Amazon account.

Designed and tested for Windows 11 x64. Windows 10 compatibility is not verified. Windows 8 and 8.1 are not supported. This release is unsigned, so Windows may show a publisher warning.

The ZIP contains the unpacked app and installation scripts. SHA256SUMS.txt provides checksums for both downloads.

## Delivery

“Email sent” means the mail server accepted the message; Amazon may take a few minutes to deliver it. Direct sending can be blocked by your network and may be unencrypted. Provider sending requires verified TLS. Browser-based email sign-in is not supported.
