Common questions

A little help getting started.

Can I use it just as a reader or image viewer?

Yes. Open Voltura Books - Browse books from Start. You don’t need a Kindle, email settings, or a Voltura account to read local files and view images. Reading and fullscreen previews never send emails.

Which files can I read and view?

The built-in reader supports EPUB, PDF, Word 97–2003 DOC, DOCX, RTF, TXT, and HTML/HTM. The image viewer supports JPEG, PNG, GIF, and BMP; animated GIFs show their first frame. Supported document formatting and embedded images are preserved, though layout can differ from the original app. Word navigation moves by a screenful.

EPUB, HTML, DOC, and DOCX reading use Microsoft Edge WebView2, normally included with Windows 11. DOC conversion also uses .NET Framework 4.8, included with Windows 11. Word and LibreOffice are not required. Where available, choose Read as text if formatted reading fails, or Open with default app.

Protected or encrypted books, password-protected PDFs, and older or damaged DOC files aren’t supported by the built-in reader. Book scripts, external links, and remote resources are blocked. HTML displays embedded content without loading companion files.

Where do I find my Kindle email?

Visit Amazon’s Content and Devices settings to find your Kindle’s Send-to-Kindle email address. In Personal Document Settings, add your sender email to the Approved Personal Document E-mail List.

Which books can I send?

EPUB books, PDF files, Word documents, and several other common formats. Choose one or several. Each file can be up to 50 MB; your email service may have a smaller limit. Password-protected or copy-protected documents may not work.

What happens if a book won’t send?

Sending pauses so you can try again, skip that book, or cancel the remaining books. Nothing is retried automatically. For several books, a summary tells you what was sent, skipped, or left unfinished.

Can I try it without sending an email?

Yes. Select Don't send emails in the Send a book window, then choose Test sending. You can browse and read supported files, or watch a simulated send. No email setup is needed for the simulation, and your sent-book history stays unchanged. Reading and fullscreen previews never send emails.

Do I need my email password?

If you send through your email provider, yes. Some services, such as Gmail, require a special password for apps; the setup form explains what to use. There is also a direct sending option without a password, though it does not work on every network.

What if my book has no cover or details?

You’ll see a full-size placeholder cover with its file type. Missing information never prevents sending. Page counts appear only when available; most EPUB books do not have a fixed number of pages. Word page counts are the values saved in the file and may change when it is opened elsewhere.

Book file types explained

The letters at the end of a filename tell you its format. For example, My book.epub is an EPUB book.

EPUB — electronic publication (.epub)
A common ebook format. Text usually adjusts to your Kindle’s screen and chosen text size. We show its cover when one is included.
PDF — portable document format (.pdf)
Pages laid out like a printed book or document. We show the first page as a preview.
RTF — rich text format (.rtf)
A text document with basic formatting, such as bold words and headings. We show a full-size placeholder cover.
Word documents (.doc, .docx)
Documents created by Microsoft Word and similar apps. Word 97–2003 DOC and DOCX files support local reading with formatting, tables, and embedded pictures, without Word or LibreOffice. Use the arrows to move by a screenful; layout can differ from Word and Kindle. Formatted reading uses Microsoft Edge WebView2, with text-only fallback if unavailable. DOC files convert locally when reading starts, using .NET Framework 4.8, included with Windows 11. Encrypted, damaged, and older DOC formats cannot be converted. Some DOCX files include a cover preview. The original file is sent unchanged.
TXT — plain text (.txt)
Words without page styling or pictures. We show a full-size placeholder cover.
HTML — web-page documents (.html, .htm)
A saved web-page file. Only that file is sent, not a folder of linked pictures. We show a full-size placeholder cover.
Pictures (.jpg, .jpeg, .png, .gif, .bmp)
Common image formats. We show the picture as the preview; for animated GIFs, the first frame.
AZW, AZW3 and MOBI
Kindle and older ebook formats that this email delivery route does not support. Use an EPUB or PDF edition instead; changing the filename ending does not convert a book.

Preview availability does not determine whether a file can be sent. Amazon’s supported file types.

Connection and compatibility details

Designed and tested for Windows 11 on an x64 PC. Windows 10 compatibility has not been verified; some icons depend on fonts included with Windows 11. Windows 8 and 8.1 are not supported. Provider sending requires verified TLS encryption. Direct sending uses port 25 and may be unencrypted if the receiving server does not offer TLS. Networks and mail servers can block direct delivery.

Browser-based email sign-in (OAuth) is not supported. Each file is sent unchanged, without conversion or DRM removal. Amazon processes the file and may reject unsupported books. The maximum attachment size is 50,000,000 bytes, before email encoding; your provider may allow less.

Does “Email sent” mean it’s on my Kindle?

It means the mail server accepted the email. Amazon still needs to process and deliver the book. If a connection fails after submission, check your Kindle before retrying so you do not send a duplicate.

What stays on my computer?

Your settings and sent-book history are stored locally. Passwords use Windows Credential Manager. There is no Voltura account or telemetry. Automatic email setup sends only your email domain to Thunderbird’s configuration service and may query DNS. Your book is sent through the delivery method you choose.

How do I update Voltura Books?

Open About in the Send a book window and choose Check for updates. The app downloads and verifies a newer version, then offers Install update when you are ready.

How do I change settings or remove the app?

Open Voltura Books - Settings from Start. To remove it, go to Windows Settings → Apps → Installed apps → Voltura Books → Uninstall. Removal also deletes its settings, saved password, and sent history.
