# Code of Conduct

Voltura Books should be a useful and welcoming project for users, testers, and contributors.

## Our standard

- Be respectful and constructive.
- Assume good intent and accept correction.
- Keep issues and pull requests focused on the project.
- Give useful details when reporting bugs or suggesting changes.

Harassment, insults, threats, discrimination, spam, deliberate disruption, and publishing private information without permission are unacceptable.

## Scope and enforcement

This code applies to the project's GitHub issues, pull requests, discussions, release comments, and other official Voltura Books communication channels.

Voltura AB may remove comments, close issues, block users, or reject contributions that violate this code. Report problems through an available private maintainer contact channel. If none is available, open a minimal public issue asking for contact without including private details.
